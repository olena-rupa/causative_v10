# causative_v10: Corpus-Based Extraction Pipeline for Causative Constructions

Модульний програмний комплекс мовою Python (на базі бібліотеки `spaCy` та модуля `DependencyMatcher`) для автоматизованого вебскрейпінгу, графового синтаксичного парсингу дерев залежностей та багатоступеневої фільтрації спонукальних (каузативних) конструкцій із вторинною інфінітивною предикацією в англійськомовному та українськомовному масмедійному дискурсі (2021–2026 рр.).

Розроблено в межах магістерської кваліфікаційної роботи на кафедрі прикладної лінгвістики Національного університету «Львівська політехніка» (2026).

## Структура репозиторію
* `causative_v10/` — ядро програмного комплексу (версія `10.0.0`):
  * `config.py` — конфігураційні параметри, реєстри медіадоменів, цільові списки дієслівних лем (`EN_BARE`, `EN_TO`, `UK_ALL`) та стоп-списки десемантизованих конструкцій (`LVC`);
  * `scraping.py` — трирівневий модуль вебскрейпінгу (Wayback Machine CDX API, XML Sitemaps, календарні архіви) та карусельного балансування джерел (`round_robin_mix`);
  * `nlp_engine.py` — графовий синтаксичний парсер (`DependencyMatcher`), фільтри пасивного стану, десемантизованих сполучень (`L1–L3`), структурні евристики валідації `Pattern B` (`B1–B4` із рекурсивним відновленням однорідного підмета) та трисигнальна модель `Confidence Score`;
  * `quota.py` — контролер стратифікованого відбору за синтаксичними шаблонами `Pattern A` та `Pattern B`;
  * `exporters.py` — генерація таблиць MS Excel та структурованих файлів для корпусного менеджера *Sketch Engine*;
* `run_en.py`, `run_uk.py` — виконавчі скрипти збору англійськомовного та українськомовного корпусів;
* `test_nlp.py` — набір із 20 модульних тестів для верифікації лінгвістичних фільтрів (`20/20 PASSED`);
* `Corpus_validator.py` — скрипт постпроцесингу, дедуплікації, перерахунку нормалізованої частотності (на 10 000 слів) за результатами експертної верифікації *Human-in-the-Loop* та генерації XML-файлів для *Sketch Engine*;
* `GOLD_corpus_EN_thesis.xlsx`, `GOLD_corpus_UK_thesis.xlsx` — верифіковані дослідницькі корпуси (1 190 англійськомовних та 860 українськомовних спонукальних конструкцій, вилучених із масиву 15 983 754 просканованих слів).
